# Dossier Certifications

Placez ici les images de vos certifications.

## Format des images

- Format recommandé : JPG ou PNG
- Taille recommandée : 800x600px ou similaire
- Nommez les fichiers selon vos certifications dans `data/profile.ts`

## Exemple

Si dans `data/profile.ts` vous avez :
```typescript
{
  name: 'Google IT Support',
  image: '/certifications/google-it-support.jpg',
  ...
}
```

Placez l'image ici avec le nom : `google-it-support.jpg`

## Note

Si une image n'est pas trouvée, elle sera automatiquement masquée dans l'affichage.
